# All In One Caribbean Cuisine — Website

A one-page website for **All In One Caribbean Cuisine** in Las Vegas, themed to the colors of the restaurant's logo (sunset orange, golden sun, turquoise ocean).

## Features
- Hero with the full logo, rising smoke effect, and a live countdown to the June 15 grand opening
- Signature menu built from the restaurant's own dish photos
- Grand-opening specials, photo gallery, and a location section with embedded map + directions
- Fully responsive (desktop and mobile)

## Structure
```
index.html        # the entire site (self-contained HTML/CSS/JS)
images/           # logo and food photography
```

## Run locally
Open `index.html` in any browser, or serve the folder:
```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```
